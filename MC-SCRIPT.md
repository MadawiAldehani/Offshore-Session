# MC run sheet — Offshore Discoveries

**10 questions · 30 seconds each · answers in bold**

Read the *"Say this"* line before starting each question, so the room knows
what it is being asked to do. The formats change a lot between questions.

## If something goes wrong

- **Someone joins late** — fine, they play every remaining question
- **Two people with the same name** — the second becomes "Sarah 2"
- **A phone locks or refreshes** — they keep their name and score
- **Nobody answered** — reveal anyway, it just scores nobody
- **You need to jump to a question** — click it in the list on the control panel
